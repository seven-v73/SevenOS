# SevenOS Prism Flow Material Direction

This file is kept at the historical path for compatibility with older checks
and references. The official identity direction is `identity/PRISM_FLOW_CHARTER.md`.

SevenOS no longer treats liquid glass as the identity. Glass is one material
inside Prism Flow.

## Material Rule

```text
Depth first. Glass second.
```

SevenOS uses:

- Prism Ink and Graphite Plane as the stable foundation
- Mineral Surface for raised panels
- Frost Line for quiet borders and separators
- profile facet accents for context
- restrained translucency only when focus or transition needs it

## Shell Surfaces

### Prism Bar

The top/system bar behaves as a Prism Bar:

- identity and Mini OS context
- Spotlight/intent entry
- active jobs and state
- trust, network, audio and power
- no decorative modules

### Context Rail

The Context Rail is the SevenOS workflow surface:

- pinned apps
- Mini OS facets
- running jobs
- folders and files
- trust state
- workflow actions

### Spotlight

Spotlight remains the only global search and intent surface. On open it should
stay quiet: search field, category icons and no noisy command list until the
user acts.

### Prism Passage

Mini OS switching uses Prism Passage to show preparation, transition,
readiness and the target facet.

## Non-Negotiables

- No oversized translucent sheets everywhere.
- No flat black-on-black utility surfaces without depth.
- No aggressive neon or cyberpunk cliche.
- No search bars outside Spotlight unless the app is a dedicated search tool.
- No decorative UI element without a real action or state.
- No direct clone branding.
